# Sample Data

This directory is reserved for sample PDF documents used during development, testing, and demonstrations.

## Notes
- Do not commit confidential or sensitive documents.
- Prefer small, non-sensitive PDFs (e.g. sample resumes, invoices, or reports) for local testing.
- Automated tests use temporary/generated data and mocks; they do not require real PDFs or external API access.
- If you add sample files, document their source and ensure you have permission to use them.
